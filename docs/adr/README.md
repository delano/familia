# Architecture Decision Records

Terse records of decisions that constrain how Familia is built. One file per
decision, numbered, never rewritten — supersede with a new ADR instead.

Format: Status, Context, Decision, Consequences. A few lines each. If it needs
more, link out to a doc under `docs/` rather than growing the ADR.

Statuses: `accepted`, `superseded by ADR-NNNN`, `rejected`.
